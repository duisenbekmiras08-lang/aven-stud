# Aven stud — персональная ИИ-учебная среда

Учебный full-stack проект (Python 3.10+) по предоставленной спецификации: один HTML-файл с встроенными CSS и Vanilla JS, Python + Flask backend, SQLite и интеграция с OpenAI API.

## Что реализовано

- Регистрация, вход, демонстрационный профиль.
- Хранение пользователей и учебного состояния в SQLite.
- Пароли и PIN хранятся как `scrypt`-хэши на сервере, а не в открытом виде.
- Сессия через HttpOnly cookie; CSRF-токен для изменяющих запросов.
- AvenAI-калибровка профиля: направление, курс, CEFR, стиль объяснения, рабочие часы и дни до сессии влияют на содержание модулей.
- Пять модулей: персональный репетитор, академический English, профессиональные симуляции, планировщик нагрузки, карта навыков и карьеры.
- OpenAI Responses API вызывается только из Python backend; для защиты от случайных расходов добавлен лимит до 12 ИИ-запросов на пользователя в час. API-ключ не отправляется браузеру.
- Учебный AI guardrail: модель направляет студента через подсказки и объяснения, а не генерирует готовую работу для сдачи.
- Фокус-таймер, чек-лист задач, словарь терминов, проверка знаний и сохранение прогресса.
- Экран блокировки PIN (демо PIN — `1234`). Для аккаунта без PIN можно разблокировать экран паролем.

## Запуск на Windows (PowerShell)

Открой PowerShell в папке проекта и выполни:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Открой `.env` в редакторе и замени `your_openai_api_key_here` своим API-ключом. Ключ хранится только на компьютере в `.env`; не вставляй его в `index.html`, JavaScript или в переписку. Укажи модель, доступную твоему API-проекту, в `OPENAI_MODEL`. У API-проекта также должны быть активны доступ и лимит расходов; сам ChatGPT-план автоматически не включает API-баланс.

Затем запусти:

```powershell
python app.py
```

Открой браузер:

```text
http://127.0.0.1:5000
```

Если ключ не настроен, интерфейс и демонстрационный режим всё равно запускаются; реальные запросы к OpenAI будут недоступны, пока не появится корректный ключ.

## Показ с телефона или второго ноутбука в той же Wi-Fi сети

Flask запускается с `host=0.0.0.0`, поэтому сервер слушает локальную сеть. Узнай IPv4-адрес ноутбука командой:

```powershell
ipconfig
```

Найди IPv4 Address адаптера Wi-Fi, например `192.168.1.105`, и на втором устройстве в той же сети открой:

```text
http://192.168.1.105:5000
```

Windows Firewall может спросить разрешение для Python — разрешай доступ только в частной сети, если это твоя доверенная домашняя/учебная сеть. Не открывай этот учебный сервер в публичный интернет.

## Важно о безопасности

Это прототип для демонстрации, а не production-сервис. Перед публикацией в интернете нужны HTTPS, сильный постоянный `FLASK_SECRET_KEY`, ограничение частоты запросов, восстановление аккаунта, резервные копии, контроль доступа, аудит и настройка хостинга. Не используй реальные пароли или личные медицинские/финансовые данные в демо. Демо-аккаунт общий для локального показа; не сохраняй в нём личную информацию.

`instance/aven_stud.sqlite3` создаётся автоматически при первом запуске и не включён в ZIP.
